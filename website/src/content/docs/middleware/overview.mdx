Zinc's middleware lives under `github.com/0mjs/zinc/middleware`, one small package each. Every package has a `New` function that takes an optional `Config`, and its zero value means the defaults:

```go
import (
	"github.com/0mjs/zinc/middleware/cors"
	"github.com/0mjs/zinc/middleware/logger"
)

app.Use(logger.New())
app.Use(cors.New(cors.Config{AllowOrigins: []string{"https://app.example.com"}}))
```

Each middleware is an ordinary `func(*zinc.Context) error`, so you can attach it to the whole app, a group, or a single route. Standard `net/http` middleware works too, through [`UseHTTP`](/guide/http-interoperability/).

## A good default stack

Most JSON APIs start here. Order matters: each entry wraps everything after it.

```go
app.Use(
	requestid.New(), // 1. tag the request first, so everything can log the ID
	logger.New(),    // 2. log every request, including failures below
	recover.New(),   // 3. turn panics into 500s that the logger records
	secure.New(),    // 4. browser security headers
)
```

Add [CORS](/middleware/cors/) when browsers on other origins call the API, [Context Timeout](/middleware/timeout/) to bound slow requests, and an auth middleware on the groups that need it.

## Put middleware where it belongs

Use app middleware for every request:

```go
app.Use(requestid.New(), logger.New())
```

Use group middleware for a route family:

```go
api := app.Group("/api", keyauth.New(keyauth.Config{Validator: validateKey}))
```

Use route middleware for one endpoint:

```go
app.Post("/exports", limiter.Concurrency(2), startExport)
```

Leave some requests out with `zinc.Skip`, which runs the middleware unless the predicate reports true:

```go
app.Use(zinc.Skip(func(c *zinc.Context) bool {
	return c.Path() == "/healthz"
}, logger.New()))
```

Read [Groups and Middleware](/guide/groups-and-middleware/) for execution order and `c.Next()`, or [Errors](/guide/errors/) for returned middleware errors.

## Contrib

Middleware with third-party dependencies lives in its own repository, [`github.com/0mjs/contrib`](https://github.com/0mjs/contrib), so Zinc's module needs nothing beyond the standard library. Each contrib package is a separate Go module, versioned on its own:

|---|---|
| [`github.com/0mjs/contrib/jwtauth`](/middleware/jwtauth/) | `github.com/golang-jwt/jwt/v5` |
